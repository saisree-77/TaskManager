# Team Task Manager

## Project Description
Team Task Manager is a full-stack web application where users can create projects, assign tasks, and track task progress using role-based access control.

## Features
- User Signup/Login
- Role-Based Access (Admin/Member)
- Create Projects
- Create Tasks
- Assign Tasks
- Task Status Tracking
- Dashboard with Task Statistics

## Technologies Used
- Java
- Servlets
- JSP
- JDBC
- MySQL
- Bootstrap
- Apache Tomcat

## Database Tables
- users
- projects
- tasks

## Role-Based Access
### Admin
- Create Projects
- Create Tasks
- View All Tasks

### Member
- View Assigned Tasks Only

## How to Run
1. Import project into Eclipse
2. Configure Apache Tomcat
3. Add MySQL Connector Jar
4. Create MySQL database
5. Run on Server
